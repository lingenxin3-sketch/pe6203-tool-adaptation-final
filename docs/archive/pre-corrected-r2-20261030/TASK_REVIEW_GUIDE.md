## Consistent review criteria

Identify the task, policy, version, and source path. Compare each requested action with the actual tool name, arguments, response, and saved artifact or service state. Describe completion as complete, partial, incomplete, or insufficiently evidenced without converting that judgment into a replacement official score. Locate disagreements between claims, scores, and evidence. Possible explanations include missed updates, harmful unnecessary changes, agent mistakes, tool errors, missing resources, or unresolved causes.

## Common pitfalls

- File existence does not prove correct content. In task 28, some saved tasks describe yesterday's database error as still unresolved without evidence from today's log.
- Some referenced `logs/` directories do not exist in the official resources. Do not fabricate them. Check whether the question needs only a plan or requires unavailable data.

AI-assisted evidence review is not independent human annotation. Report discrepancies separately and retain all original scores.
